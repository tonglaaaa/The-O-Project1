# The O Massage And Beauty Website

This folder is a backend-ready version of the original single-file HTML prototype.

## Structure

- index.html: page markup and section structure
- css/styles.css: visual design, layout, responsive styles, and animation styles
- js/main.js: browser interactions such as sticky header, mobile menu, and scroll reveal
- assets/images/: future local image files
- data/site-content.json: starter content model for future backend or CMS data

## Future Backend Notes

Good next backend features would be:

- booking form submission
- admin panel for editing services and prices
- customer contact storage
- reviews loaded from a database or external API
- service/package data loaded from JSON or backend API instead of hardcoded HTML

For now, the website still works as a static frontend by opening index.html in a browser.
